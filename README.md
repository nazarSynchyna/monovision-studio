## About the Project

This project is my first educational web development application. Its main goal was to master pixel-perfect layout implementation, semantic markup, and responsive design principles without relying on heavy external CSS frameworks.

Key focus areas during development:
* Proper implementation of semantic HTML5 elements for SEO and accessibility.
* Building a reliable responsive grid that adapts flawlessly from smartphones to ultra-wide monitors.
* Organizing assets efficiently for rapid loading times and optimized browser rendering.

## How to Install & Run

Since this is a static frontend project, there are no heavy backend compilers or databases to install. You can easily run it locally in a few seconds.

### 1. Clone the repository
git clone [https://github.com/nazarSynchyna/Monovision_Studio.git](https://github.com/nazarSynchyna/monovision-studio.git)

### 2. Navigate to the source folder
cd Monovision_Studio/src

### 3. Open in your browser
Simply double-click the index.html file, or if you are using VS Code, right-click index.html and select "Open with Live Server" to view real-time changes while editing.

##  Usage & Features

### Core Capabilities:
* **Fully Responsive:** Uses clean CSS Media Queries to switch layouts seamlessly between mobile, tablet, and desktop views.
* **Interactive Elements:** Features custom hover states for buttons, navigation links, and image cards.
* **Directory Structure:** All project resources are strictly isolated to maintain a maintainable codebase:
  * /css houses stylesheets.
  * /img and /logo store visual content and brand assets.
  * /icons contain vector UI icons.

---

##  Technologies Used

The project is built entirely on native web technologies to ensure maximum performance and lightweight footprint:

* **Markup:** Semantic HTML5
* **Styling:** CSS3 (Flexbox, Grid, Custom Properties/Variables)
* **Hosting:** GitHub Pages
* **CI/CD:** GitHub Actions (automated deployments on every master push)
