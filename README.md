# Monovision Studio Landing Page

Responsive educational landing page for **Monovision Studio** built with semantic HTML and modern CSS.  
The project demonstrates clean layout structure, adaptive design, and polished visual styling for a studio/presentation website.

**Live Demo:** https://nazarsynchyna.github.io/monovision-studio/

---

## Overview

This repository contains a front-end landing page project focused on:
- responsive behavior across screen sizes,
- clear content hierarchy,
- modern UI styling and section-based page composition.

It is designed as an educational project and portfolio-ready example of a static web page.

## Installation & Setup

### 1) Clone repository
```bash
git clone https://github.com/nazarSynchyna/monovision-studio.git
cd monovision-studio
```

### 2) Run locally
Since this is a static project, you can open `index.html` directly in browser.

For better local development, use a local server (recommended):

#### Option A: VS Code Live Server
- Install **Live Server** extension
- Open project folder
- Right click `index.html` → **Open with Live Server**

#### Option B: Python HTTP server
```bash
python -m http.server 5500
```
Then open: `http://localhost:5500`

## Deployment

This project is deployed with **GitHub Pages**.

If you want to redeploy:
1. Push latest changes to `main`
2. Go to **Settings → Pages**
3. Select branch: `main` (root)
4. Save and wait for deployment
